## 真实模型结果与修复

首次脚本的前五步通过，第六步收到 `finish_reason=stop` 但正文仅为空白，执行器正确拒绝，没有执行本轮任务操作。诊断只使用合成对话，不打印密钥。

修复：保留完整对话，并在最新用户消息前加 JSON 规划格式提醒。空白或非法 JSON 最多重试一次，网络、截断和业务 schema 错误不重试；整体25秒超时取消在途请求，任务写入仍最多一次。

修复后 `npm run verify:live` 从空临时清单重跑12轮全部通过，包含官方六步、空历史、真实服务进程重启、洗衣服语义变化及最近任务指代。浏览器也使用真实模型独立重跑，通过六步及刷新、重启和同名澄清补验。尚未做大规模自由表达评测或统计端到端延迟分布、实际总 token/账单费用，不据此宣称通用准确率。
